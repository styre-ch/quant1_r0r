## 运行步骤 / How to Run

以下命令在项目根目录的PowerShell中逐条执行。

### 1. 创建虚拟环境

首次配置时执行；已有`.venv`则无需重复创建。

```powershell
python -m venv .venv
```

### 2. 安装依赖

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. 下载示例行情

```powershell
.\.venv\Scripts\python.exe step01_download.py
```

数据保存至：

```text
data/raw/000001_2024_unadjusted.csv
```

重新运行下载脚本会覆盖该示例CSV。已有数据时，可以直接执行后续检查。

### 4. 检查本地行情

```powershell
.\.venv\Scripts\python.exe step02_check.py
```

### 5. 核对交易日历

请先确认项目中存在`step03_calendar_check.py`。

```powershell
.\.venv\Scripts\python.exe step03_calendar_check.py
```

本次获取的交易日历保存至：

```text
data/raw/trading_calendar_2024_sina.csv
```
